# Git ажлын дараалал

1. Өдөр бүр ажлаа эхлэхээсээ өмнө: `git pull`
2. Өөрийн салаа үүсгэх: `git checkout -b eddie/admin-actions` (эсвэл `urnaa/onboarding-page`)
3. Ажлаа хийж хадгалах: `git add .` ба `git commit -m "Add onboarding page"`
4. GitHub руу илгээх: `git push -u origin eddie/admin-actions`
5. GitHub дээр **Pull Request** нээж, нөгөө хүн нэг харсны дараа `main` руу нэгтгэнэ.

Нэг ажил нэг салаа. Жижиг, олон удаагийн commit хий.
